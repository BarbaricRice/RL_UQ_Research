# Basic roadmap to basic functionality
1. Create functions to extract information from ifc model geometry. i.e. rooms, object locations etc.
2. calculate distances between rooms using geometry locations
3. calculate longest travel path (or just long paths of travel)
4. scale up model (build more rooms and paths)
5. re-verify results with new model
6. Future refinements:
   1. write something to visualise this network
   2. randomise the layout?
